# Chain Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold and configure the Vertix Layer 1 blockchain chain foundation — a bootable chain with all standard Cosmos SDK modules wired, zero-inflation enforced (no `x/mint`), and Vertix chain identity (binary: `vertixd`, bech32: `vtx`, denom: `uvtx`).

**Architecture:** Use Ignite CLI v28.x to scaffold the chain skeleton, then customize `config.yml` for Vertix identity and genesis parameters, remove `x/mint` from `app/app.go` to enforce the 21M VTX hard cap, and set up CI/CD and developer tooling. The chain uses `x/distribution` for fee-based staker rewards; there is no inflation minting.

**Tech Stack:** Cosmos SDK v0.50.x, CometBFT v0.38.x, Go 1.22+, Ignite CLI v28.x, golangci-lint v1.57+, GitHub Actions

BINARY      := vertixd

               -X $(MODULE)/version.AppName=$(BINARY) \
               -X $(MODULE)/version.Version=$(VERSION) \
               -X $(MODULE)/version.Commit=$(COMMIT)

.PHONY: build install test lint proto-gen clean devnet-reset all

all: lint test build

## Build the vertixd binary
build:
	@echo "Building $(BINARY)..."
	@go build -mod=readonly -ldflags "$(LDFLAGS)" -o $(BUILD_DIR)/$(BINARY) ./cmd/vertixd
	@echo "Binary at $(BUILD_DIR)/$(BINARY)"

## Install vertixd to GOPATH/bin
install:
	@go install -mod=readonly -ldflags "$(LDFLAGS)" ./cmd/vertixd

## Run all unit and integration tests
test:
	@go test -mod=readonly -race -count=1 ./... -timeout 10m

## Run tests with coverage
test-cover:
	@go test -mod=readonly -race -count=1 -coverprofile=coverage.out ./...
	@go tool cover -html=coverage.out -o coverage.html
	@echo "Coverage report: coverage.html"

## Run golangci-lint
lint:
	@golangci-lint run --timeout 5m ./...

## Generate protobuf Go code
proto-gen:
	@ignite generate proto-go

## Generate TypeScript client
ts-gen:
	@ignite generate ts-client

## Validate genesis
validate-genesis:
	@$(BUILD_DIR)/$(BINARY) genesis validate-genesis

## Start devnet with reset
devnet-reset:
	@ignite chain serve --reset-once

## Start devnet (keep state)
devnet:
	@ignite chain serve

## Remove build artifacts
clean:
	@rm -rf $(BUILD_DIR)/ coverage.out coverage.html

## Show help
help:
	@echo "Available targets:"
	@grep -E '^## ' Makefile | sed 's/^## /  /'

## Task 8: Set Up GitHub Actions CI

**Files:**
- Create: `.github/workflows/ci.yml`

- [ ] **Step 1: Create .github/workflows/ci.yml**

```yaml
name: CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]

env:
  GO_VERSION: "1.22"

jobs:
  lint:
    name: Lint
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-go@v5
        with:
          go-version: ${{ env.GO_VERSION }}
          cache: true

      - name: golangci-lint
        uses: golangci/golangci-lint-action@v4
        with:
          version: v1.57.2
          args: --timeout 5m

  build:
    name: Build
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-go@v5
        with:
          go-version: ${{ env.GO_VERSION }}
          cache: true

      - name: Build binary
        run: make build

      - name: Upload binary artifact
        uses: actions/upload-artifact@v4
        with:
          name: vertixd
          path: build/vertixd

  test:
    name: Test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-go@v5
        with:
          go-version: ${{ env.GO_VERSION }}
          cache: true

      - name: Run tests
        run: make test

      - name: Run test coverage
        run: |
          go test -mod=readonly -count=1 -coverprofile=coverage.out ./...
          go tool cover -func=coverage.out | tail -1

  validate-genesis:
    name: Validate Genesis
    runs-on: ubuntu-latest
    needs: build
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-go@v5
        with:
          go-version: ${{ env.GO_VERSION }}
          cache: true

      - uses: actions/download-artifact@v4
        with:
          name: vertixd
          path: build/

      - name: Make binary executable
        run: chmod +x build/vertixd

      - name: Initialize and validate genesis
        run: |
          build/vertixd init test-node --chain-id vertix-ci-1 --home /tmp/vertix-ci
          build/vertixd genesis validate-genesis --home /tmp/vertix-ci
```
